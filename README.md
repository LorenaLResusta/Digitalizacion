## Cómo editar

- La portada está en `content/_index.md`.
- Cada unidad es una carpeta (`content/ud01`, `content/ud02`…). Su `_index.md` contiene la ficha de la unidad y cada subcarpeta es un apartado, con su texto en `index.md` y sus imágenes al lado.
- El orden de los apartados lo marca `weight` en la cabecera de cada archivo.
- Al subir cambios a `main`, GitHub Actions genera la web con [Hugo](https://gohugo.io/) y el tema [Relearn](https://mcshelby.github.io/hugo-theme-relearn/) y la publica en unos minutos.
