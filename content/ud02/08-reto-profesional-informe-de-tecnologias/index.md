**Objetivo:** elaborar el informe que pide la dirección de Juniverse Studio (criterio de evaluación *g*).

**Tareas:**

1. Elige **seis THD** de esta unidad.
2. Para cada una, completa una ficha:

| Campo | Contenido |
|-------|-----------|
| Tecnología | Nombre |
| Qué es | Explicación en dos o tres líneas, con tus palabras |
| Características | Tres rasgos principales |
| Área de aplicación | Planta, negocio o ambas; departamentos concretos |
| Ejemplo real | Una empresa u organización que la use (con enlace a la fuente) |
| Mejora que aporta | Productividad, calidad, sostenibilidad, cliente… |
| Riesgos | Seguridad, coste, privacidad… |
| ¿Útil para Juniverse o para la cadena de tiendas? | Sí/No y por qué |

3. Cierra el informe con una **recomendación**: las dos tecnologías que implantarías primero y por qué.

**Entregable:** informe de 3–4 páginas o infografía, citando las fuentes consultadas.
